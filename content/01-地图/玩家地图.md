### 制造/B端基因 vs 营销/电商基因

```
制造 · B端 · 可核实              营销 · 电商 · 声量大
舒华（1996，A股605299）    ←→   麦瑞克（2018，前阿里电商团队）
                                亿健（2006，线上品牌）
                                易跑（2010）
```

**舒华是唯一"从 B 端打到 C 端"的国产玩家**：做商用、做政府全民健身采购、做冬奥赞助，再把背书带到家用市场。麦瑞克走的是完全相反的路——**电商团队切入健身器材**（创始人罗卫波是 85 后电商操盘手，联创中有前阿里员工）。

> 💡 这个差异直接影响带货配合度：**麦瑞克懂达人生态、素材现成、配合度高**；**舒华信任状硬但线上营销弱**。

## 竞争格局

### 按赛道切分

```
商用 B 端        Life Fitness / Technogym / Precor / 舒华
   ¥5-18 万      ← 招投标渠道，与直播间无关

高端家用+内容    NordicTrack / Peloton
   ¥1-3 万       ← 中国渠道弱，做对标不做带货

家用线上主力     麦瑞克 / 亿健 / 易跑 / 佑美 / 舒华
   ¥1,500-4,000  ← ★ 抖音带货真正的战场

低价白牌         拼多多杂牌
   ¥500-1,500    ← 不建议触碰
```

### 关键洞察

1. **ICON 一家占全球 60%+** — 跑步机不是分散市场，制造端高度集中
2. **制造底盘 + 内容 > 纯内容** — NordicTrack（1977 制造起家）比 [[../02-品牌/Peloton|Peloton]]（2012 内容起家）抗风险能力强得多，详见 [[行业概览]]
3. **国产四强的差异化已经形成**：麦瑞克=折叠科技、亿健=静音性价比、易跑=马拉松爬坡、佑美=极致低价（但品控塌方）
4. **爬坡是当前最大的增量需求** — 易跑 M5 Pro、麦瑞克 X5、舒华 A9 在 3,000 元档正面交火
