# 消费人群画像

> 🔴 **本页最重要的发现：跑步机的真实买家是女性（占比超 65%），但全网跑步机内容几乎都是男性向的（马力、参数、爬坡）。**
> 这是一个巨大的供需错配，也是本库发现的最大内容机会。

## 🔴 核心错配：谁在买 vs 内容在讲给谁

| | 数据 | 现状内容 |
|---|------|---------|
| **性别** | **女性消费者占比超 65%** | 🔴 讲马力、峰值、无刷电机、Shore A 硬度——**典型男性向参数话术** |
| **家庭结构** | **已婚已育人群消费金额占比近 80%** | 🔴 几乎没有"家庭场景"内容 |
| **城市** | **二至四线城市线上购买力更强** | 🔴 内容默认一线都市白领视角 |
| **价格** | **客单价 <¥1,000 占 40%**，是主流可接受带 | 🔴 品牌主力在 ¥1,500-4,000 |

> 💡 **这四条错配每一条都是内容机会。** 尤其第一条——把跑步机内容从"参数评测"转向"女性/家庭视角"，是目前几乎没人做的方向。

## 家庭健身核心人群

### 年龄与性别

| 维度 | 数据 |
|------|------|
| 主力年龄 | **25-35 岁**是居家健身主要购买力 |
| **性别** | **女性占比 >65%** ⭐ |
| 高消费群体 | **精致妈妈**、**新锐白领**——青睐智能产品 |
| 家庭结构 | **已婚已育消费金额占比近 80%**；95 后单身群体购买金额超 50% |

### 城市分布

**二至四线城市对线上健身器械购买力更强。**

原因推测（待验证）：
- 一线城市健身房密度高、通勤方便，居家健身替代需求弱
- 二三四线**住房面积更大**（跑步机最大障碍是空间）
- 线下健身器材专卖店少，只能线上买

> ⭐ **这条对投放定向直接有用**：不要把预算全砸一线。

### 价格接受度 ⚠️

| 价格带 | 占比 |
|--------|------|
| **<¥1,000** | **40%（最高）** |
| ¥1,000-2,000 | — |
| ¥2,000+ | — |

> 🔴 **关键矛盾**：主流用户心理价位 <¥1,000，而国产品牌主力款在 ¥1,500-4,000。
>
> **这解释了两件事**：
> 1. 为什么 [[../02-品牌/佑美|佑美]] W999 能用 ¥798 卖爆（也解释了它为什么质量塌方——这个价格做不出可靠产品）
> 2. 为什么跑步机直播退货率高达 30-50%——**价格超出心理预期的冲动下单，冷静后就退**
>
> **应对**：不要硬推高客单。用 ¥1,300-1,700 档（[[../02-品牌/立久佳|立久佳]] 暴汗猛犸、[[../02-品牌/亿健|亿健]] 睿智 X5）承接主流需求，高客单做专场而非日播。

## 六类可定向人群

### 1. 精致妈妈 / 已婚已育女性 ⭐⭐⭐⭐⭐

**为什么是第一优先级**：女性 >65% + 已婚已育近 80%，两个最大特征的交集。

| | 内容 |
|---|------|
| 核心诉求 | 产后恢复、带娃间隙锻炼、不用出门 |
| 真实顾虑 | **孩子安全**（童锁）、噪音吵到孩子睡觉、占地方 |
| 匹配产品 | [[../02-品牌/立久佳\|立久佳]] H1（**童锁+疲劳降速**）、[[../02-品牌/易跑跑步机\|易跑]] M1 Ultra（折叠 0.2㎡） |
| 内容角度 | 家庭场景、带娃 VLOG、"孩子睡着了我还能练" |

> ⭐ **童锁功能几乎没有品牌当主卖点讲**，但对这个人群是决定性的。见 [[机会表#b3-家有老人小孩的家庭|机会 B3]]。

### 2. 大体重 / 膝盖敏感人群 ⭐⭐⭐⭐⭐

| | 内容 |
|---|------|
| 核心诉求 | **不能跑但要减脂** |
| 解法 | **走坡**——消耗高于平地走，冲击远小于跑步 |
| 匹配产品 | 带电动坡度机型（[[../02-品牌/易跑跑步机\|易跑]] M5 Pro、[[../02-品牌/立久佳\|立久佳]] R8） |
| 内容角度 | 《膝盖不好还能减脂吗？走坡比跑步管用》 |
| ⚠️ 注意 | **必须看承重参数**，也别推 MINI 线（电机弱、减震差） |

详见 [[../03-技术/坡度系统|坡度系统]]。

### 3. 二三四线家庭 ⭐⭐⭐⭐

| | 内容 |
|---|------|
| 优势 | 住房面积大（空间障碍小）、线下渠道少 |
| 价格敏感 | 高——主力 ¥1,000-2,000 |
| 内容角度 | 实用、耐用、售后有保障，**别讲设计感** |
| 匹配 | [[../02-品牌/亿健\|亿健]] 睿智 X5、[[../02-品牌/立久佳\|立久佳]] 暴汗猛犸 |

### 4. 小户型 / 租房青年 ⭐⭐⭐⭐

| | 内容 |
|---|------|
| 核心顾虑 | **空间第一**，其次噪音（合租/薄墙） |
| 匹配产品 | [[../02-品牌/麦瑞克\|麦瑞克]] 小白犀（1 秒纯平折叠）、**[[../02-品牌/易跑跑步机\|易跑]] M1 Ultra**（0.2㎡，**且有 13.5° 坡度**） |
| 内容角度 | 折叠演示 + 推进床底实拍 |
| ⚠️ 风险 | **租房搬家频繁** → 大件是负担，成交前要提示 |

### 5. 180cm+ 高个 ⭐⭐⭐

| | 内容 |
|---|------|
| 痛点 | 跑带太短，步幅被限制；多数机型未标长度 |
| 需求 | 跑带 **140cm+ × 48cm+** |
| 匹配 | [[../02-品牌/麦瑞克\|麦瑞克]] 幻影系列（1.4M）、[[../02-品牌/舒华体育\|舒华]] X3 |
| ✅ 最优 | **[[../02-品牌/易跑跑步机\|易跑]] M5 系列**——跑带 **520mm 宽 × 1350-1420mm 长**，商用级尺寸 |
| ⚠️ 避雷 | [[../02-品牌/舒华体育\|舒华]] A9 官方适配仅 <175cm |

详见 [[../03-技术/跑带与跑板|跑带与跑板]]。

### 6. 银发 / 康复人群 ⭐⭐

| | 内容 |
|---|------|
| 诉求 | 慢走、康复、安全 |
| 关键功能 | 低速稳定、扶手、**紧急停止/疲劳降速** |
| 购买决策人 | **通常是子女买给父母** → 内容要打给中年子女 |
| 证据等级 | low，待验证 |

## 🎯 投放定向建议

| 维度 | 建议 |
|------|------|
| **年龄** | **25-35 岁为主**，可放宽至 40 |
| **性别** | 🔴 **不要默认男性**——女性占比 >65%，至少均衡投放 |
| **地域** | **二至四线城市加权**，不要全砸一线 |
| **兴趣标签** | 家居、健身、减肥、母婴（精致妈妈）、家装 |
| **行为** | 近 30 天浏览健身器材 / 减肥内容 |
| **消费能力** | 中及中高（⚠️ 但心理价位 <¥1,000 是主流，高客单需强说服） |
