# Peloton

> ⚠️ **不是带货标的**（中国不做主流零售）。
> **价值在于它是"纯内容模式"的失败样本**——理解它，才能理解为什么国产品牌都不走订阅路线。

## 一句话判断

**智能健身订阅模式的开创者，也是它的反面教材。** 硬件引流、内容变现的故事讲得最好，但**疫情后股价暴跌 80%+**，证明了**没有制造底盘的内容模式抗风险能力极弱**。

## 基本信息

| 项目 | 内容 |
|------|------|
| 成立 | **2012 年** |
| 上市 | 纳斯达克 **PTON** |
| 总部 | 美国纽约 |
| 主要产品 | Peloton Bike、**Peloton Tread**（跑步机） |
| 硬件售价 | $2,495-$4,295 |
| 订阅 | 月费约 $44（直播 + 录播课程） |

**核心逻辑**：硬件引流 → 订阅变现 → 内容做护城河
**财务特征**：订阅收入占比超 40%；硬件利润薄；近年持续亏损

---

## 🔴 核心洞察：制造底盘 + 内容 > 纯内容

这是本页对本库最重要的贡献——**两种路线的对照实验**：

| | **[[NordicTrack\|NordicTrack]] / ICON** | **Peloton** |
|---|---|---|
| 起点 | **制造起家（1977）**，后加内容 | **内容起家（2012）**，硬件是载体 |
| 规模 | **占全球跑步机 60%+ 份额** | 单一品牌 |
| 内容 | iFIT，虚拟实景跑 | 直播课 + 社区排行榜 |
| 硬件毛利 | 靠规模盈利 | 亏损 |
| **抗风险** | ✅ **强** | 🔴 **弱——需求回落即承压** |
| 疫情后 | 稳 | **股价暴跌 80%+** |

> 💡 **同样的结论在国产也成立**：
> [[麦瑞克|麦瑞克]]（2018 电商团队起家）营销强但制造积累浅，
> [[舒华体育|舒华]]（1996 制造起家）叙事弱但底盘厚——**长期看，有厂的活得久**。

## 对中国市场的三个启示

| 启示 | 说明 |
|------|------|
| **订阅模式在中国失效** | 付费意愿低 + 内容成本高 + **短视频平台海量免费健身内容** |
| **内容制作成本极高** | 专业教练、直播制作，国产品牌承担不起 |
| **国产的变通做法** | **App 免费 + 硬件溢价**（[[易跑跑步机\|易跑]] YPOO FIT、[[../02-品牌/NordicTrack\|iFIT]]） |

## 🎬 内容素材价值

**可用选题**：《为什么美国最火的跑步机在中国卖不动？》

- 反常识开场，完播率高
- 讲清"中国用户不为内容付费"的国情
- 自然引出国产品牌的性价比逻辑
- **建立行业视野的专业人设**

> ⚠️ 不要在带货视频里花太多时间讲 Peloton——**它离你的观众太远**。适合做 1-2 条建立人设的内容，不适合反复讲。
