# 跑带与跑板

> 决定"跑起来舒不舒服"和"适不适合你身高"的基础规格。**也是退货率里"人机不匹配"那一部分的主因。**

## 跑带尺寸：宽度决定跑姿，长度决定步幅

### 宽度基准

| 宽度 | 适用 |
|------|------|
| 42-44 cm | 🔴 偏窄，走路可以，**跑步易踩边** |
| 45-47 cm | 及格线，日常够用 |
| **48-51 cm** | ✅ **推荐区间**，有助于形成正确跑姿 |

> 业内建议购买 **460-510mm 宽**跑带——**跑姿会自然放松，不用刻意收着跑**。

### 长度与身高

跑带长度决定能容纳的步幅。**身高越高、速度越快，需要越长的跑带。**

| 长度 | 适用 |
|------|------|
| < 120 cm | 走步 / 慢跑，适合矮个 |
| 125-135 cm | 主流家用 |
| **140 cm+** | 高个 / 快跑，[[../02-品牌/麦瑞克\|麦瑞克]]称之为"黄金步频加长跑道" |

## 跑板与免加油技术

### 跑板结构

跑板是承接冲击的核心部件，各家的减震方案都体现在跑板上——详见 **[[减震技术|减震技术]]**：

| 品牌 | 跑板方案 |
|------|---------|
| [[../02-品牌/麦瑞克\|麦瑞克]] | 12 块分布式"龙鳞"跑板矩阵 + 双层 |
| [[../02-品牌/易跑跑步机\|易跑]] | 悬浮跑板 + 4 块异硬度减震砖 |
| [[../02-品牌/立久佳\|立久佳]] | 磁悬浮上下跑板分离 |

### 免加油 / 自润滑 ⭐ 被低估的卖点

**传统跑步机需要定期给跑带涂硅油**，不保养会导致：
- 噪音明显变大（见 [[静音与振动|静音与振动]]）
- 摩擦增大 → 电机负载升高 → 寿命缩短

**问题是：绝大多数家用用户根本不知道要保养，也不会做。**

| 方案 | 代表 |
|------|------|
| **高分子自润滑跑板** | [[../02-品牌/立久佳\|立久佳]] |
| **跑带免加油** | [[../02-品牌/易跑跑步机\|易跑]] M5 Pro |

> 💡 **"免加油"直击家用用户"不会保养"的真实痛点**，但品牌普遍把它写在参数表末尾，几乎没人在内容里讲。**这是现成的差异化话术。**

## 🎬 带货内容用法

### 尺寸必须做人群匹配

跑带规格是**最容易做"一句话选型"的参数**：

| 用户特征 | 建议 |
|---------|------|
| 身高 175cm+ / 想快跑 | 跑带 **140cm 长、48cm+ 宽** |
| 常规家用、以走跑为主 | 125-135cm × 45-48cm |
| 只走路 / 空间极小 | 可接受 42-44cm（但**说清不适合跑**） |

### 演示动作

1. **卷尺实测跑带宽度**（比口播"48 公分"有力得多）
2. 主播站上去，**双脚自然分开的余量**（直观展示够不够宽）
3. 快走 / 小跑，展示步幅是否被限制

### 话术：免加油的讲法

> "还有个事没人跟你说：传统跑步机要定期涂硅油的，不涂就越用越吵，电机还容易烧。你会记得涂吗？我猜不会。这台是自润滑跑板，免加油——听着不起眼，但这是你三年后还愿意用它的原因。"

### 高价值选题

**《跑步机越用越吵？不是坏了，是你少做了一件事》**
→ 润滑保养科普，建立专业度，自然引出免加油机型。与 [[静音与振动|静音与振动]] 页共用素材。
