# 话术与卖点

> 📌 **本页所有话术均基于本库已核实的事实**，未使用任何品牌方未经证实的宣传口径。
> 🔴 **先读[合规红线](#-一合规红线先看这段)再用。**

---

## 🔴 一、合规红线（先看这段）

### 绝对不能说的

| ❌ 禁用 | 原因 |
|--------|------|
| **"销量第一""市占率第一""X 连冠"** | 绝对化用语违反广告法；且本品类各家口径**互相冲突、自己也对不上**（见下） |
| "减震比 XX 好 49 倍" | 引用的是**竞品攻击素材**，不实且会被拆穿 |
| "一个月瘦十斤""多消耗 50% 卡路里" | 虚假宣传风险；效果因人而异，达不到必退货+差评 |
| "质量放心，用十年没问题" | 无法兑现的承诺 |
| "治疗/康复/降血压"等 | 医疗功效宣称，严重违规 |

### 为什么"第一"特别危险

本品类的宣传注水程度异常高，**已核实的口径矛盾**：

| 矛盾 | 内容 |
|------|------|
| 跨品牌冲突 | [[../players/麦瑞克\|麦瑞克]]称"2025 家用跑步机市占第一"，[[../players/亿健\|亿健]]称"天猫连续六年第一" |
| **麦瑞克自相矛盾** | "八连冠" vs "五连冠"；"50 多国" vs "20 多国" |
| 亿健口径过期 | "天猫六年第一"是**历史数据**，非当前 |

> 🔴 引用任何一方的"第一"，等于同时承担**平台违规**和**竞品投诉**两重风险。

### ✅ 安全替代

| 不说 | 改说 |
|------|------|
| "销量第一" | "月销超三万件"（具体数字） |
| "行业最好的减震" | "有 SGS 第三方测试报告" |
| "绝对不吵" | "标称 45 分贝以内，我现场测给你看" |

## 二、开场话术：劝退式筛人

> **跑步机直播第一件事不是促单，是筛人。** 退货率 30-50% 的品类里，筛人就是利润管理。

### 标准开场（0-3 分钟）

```
家人们，买跑步机之前我先问你们六个问题——

一、你家住几楼？
二、楼下住人吗？
三、木地板还是瓷砖？
四、电梯能进吗？
五、没电梯的话谁搬？
六、打算放哪儿，量过尺寸没有？

这六个问题想不清楚，今天别下单。
我不冲量，我就想让买走的人都不退。
```

### 为什么有效

1. **反套路**——所有人都在催单，你在劝退，注意力立刻抓住
2. **建立信任**——观众知道你不是纯卖货的
3. **真实降退货率**——把必退订单挡在门外

## 三、按技术点的讲解话术

### 3.1 折叠（最强演示点）

**演示优先，话术其次。前 3 秒不要说话。**

```
（一脚踩下，跑步机 1 秒折平——静音画面）

……看到了吧。

这个动作我不解释了，你自己看。
折完推床底、立墙边都行。
我拿瑜伽垫比一下——就这么大点地方。
```

**答疑：折起来到底多大？**
> "大概一张单人床垫立起来的宽度。你现在就去量你要放的那面墙，够 80 公分就行。"

**答疑：折叠机构会不会用久了坏？**
> "好问题。折叠结构确实是跑步机最容易出问题的地方之一，所以我不推荐结构特别复杂的。这台是纯平折叠，机构简单。质保条款我放评论区，你自己核对。"

---

### 3.2 减震（三条路线，别站队）

**中立讲法（可同时挂三个链接）**：
```
减震现在国产是三条路子。

麦瑞克走材料——超临界发泡，跟高端跑鞋中底一个思路，有 SGS 报告。
易跑走结构——悬浮跑板加四块减震块，前面两块软后面两块硬，
　　　　　　落地缓冲、蹬伸回弹，这设计挺讲究，也有 SGS。
立久佳走磁力——高铁那个磁悬浮，上下跑板靠磁力斥开。

三个路子不一样，不是谁碾压谁。看你预算和需求。
```

**演示动作**：同高度落球，对比回弹高度。

**答疑：减震有用吗？**
> "有用，但别指望它把你膝盖治好。它的作用是把落地那一下的冲击吃掉一部分。你要是本来就有伤，跑步机再好也解决不了——那种情况我建议你走坡，别跑。"

---

### 3.3 噪音与振动（最容易讲错的点）

🔴 **这是全品类最有价值的一段话术，因为几乎没人讲对。**

```
我跟你说个别家不会讲的事。

跑步机吵不吵，主要不看分贝——真正让楼下敲门的是振动，
是你脚落地那一下，透过楼板传下去的。

所以光买"静音款"没用。
你得配个减震垫，或者铺块厚地毯。

这台减震做得好，本身吃掉一部分冲击，
但垫子该加还得加。
```

**为什么这段值钱**：
1. 主动暴露品类局限 → 可信度飙升
2. 给了解决方案 → 消除顾虑
3. **顺势带减震垫**（连带销售）

**演示**：分贝仪测机器旁 → **镜头切到楼下再测一次**（🔴 第二步是关键）

**答疑：会不会吵到楼下？**
> "实话说，任何跑步机都有可能。但你可以控制——减震垫加上、别在晚上十点后跑、走坡比快跑安静得多。这三条做到，被投诉的概率很低。"

---

### 3.4 电机与马力（最大参数陷阱）

```
你买跑步机是不是看马力越大越好？

我告诉你个事：健身房那台十六万的商用机，
只标持续马力，从来不标峰值。

峰值是瞬间爆发，持续才是真实耐力。
一匹持续马力能带 50 到 60 公斤。

家用 1.5 到 2 匹持续马力就够了，
超过这个数对你就是溢出，多花的钱换不来体感。
```

**答疑：这台才 1.25 马力，太小了吧？**
> "这个 1.25 是**持续马力**，不是峰值。别家标 5 马力那是峰值，换算成持续可能就 1.5。你多重？……那这台完全够。参数要看对地方。"

---

### 3.5 坡度（档位 ≠ 角度）

```
看到"32 档坡度"别激动，档位不等于角度。

档位是把最大坡度切成多少份，
真正决定陡不陡的是最大角度，单位是度。

我给你量一下这台实际能升到多少度。
```

**答疑：为什么要买带坡度的？**
> "同样走 30 分钟，加个坡消耗能差一大截，**而且比加速跑对膝盖友好得多**。体重大的、膝盖不好的，走坡比跑步安全。这也是现在中端机都在卷坡度的原因。"

> ⚠️ **不要给具体减脂数字**（"多消耗 50%"），定性不定量。

---

### 3.6 跑带尺寸

```
（拿卷尺现场量）

跑带宽度我量给你看——520 毫米。

行业建议是 460 到 510，这台超了。
这个宽度你跑起来不用刻意收着，姿势能放开。
```

**按身高选型**：
| 用户 | 建议 |
|------|------|
| 175cm+ / 想快跑 | 跑带 140cm 长 × 48cm+ 宽 |
| 常规家用 | 125-135cm × 45-48cm |
| 只走路 | 可接受更窄，但**说清不适合跑** |

---

### 3.7 免加油 / 保养

```
还有个事没人跟你说：

传统跑步机要定期涂硅油的。不涂就越用越吵，电机还容易烧。
你会记得涂吗？我猜不会。

这台是自润滑跑板，免加油——
听着不起眼，但这是你三年后还愿意用它的原因。
```

## 四、按品牌的差异化话术

> 每个品牌只讲它最强的那一个点，**不要平铺所有参数**。

| 品牌 | 唯一主打 | 一句话 |
|------|---------|--------|
| **[[../players/麦瑞克\|麦瑞克]]** | 折叠 | "一脚踩下去，1 秒折平，塞床底" |
| **[[../players/易跑跑步机\|易跑]]** | **燃动三模式** | ⭐ **"跑步机还能倒着走？"**（独家，竞品零对标） |
| **[[../players/立久佳\|立久佳]]** | 磁悬浮 | "高铁靠磁悬浮不颠，这台跑步机也是" |
| **[[../players/舒华体育\|舒华]]** | **可核实的背书** | "冬奥会用的牌子，A 股上市，财报你自己能查" |
| **[[../players/亿健\|亿健]]** | 稳妥 | "不折腾，就要个能用五年的" |

### 面对"没听过这个牌子"

**立久佳**：
> "立久佳 2006 年就在浙江永康做跑步机了，永康是中国五金之都，自己有厂。你可能没听过它，但你听过荣耀吧？这台是荣耀亲选的联名款。"

**易跑**：
> "易跑 2010 年的牌子，主打马拉松跑步机。它的减震有 SGS 认证，跑带 520 毫米是商用级宽度。就是不太会打广告。"

**舒华**：
> "舒华你可能没注意，但你去过的健身房大概率有它的器材。1996 年的公司，A 股上市代码 605299，冬奥会赞助商——**这些你都能自己查**。"

## 五、面对竞品质疑

**Q：XX 家说他们减震比你这个好 49 倍？**
> "那个数据是品牌自己委托测的，而且拿他家最新款比对方旧款。我不引用这种数。**两家现在都有 SGS 认证**，路线不同而已——一个走材料，一个走结构。你要真在意，我把两家的演示都做给你看。"

**Q：为什么不推销量第一的那个牌子？**
> "'第一'这个词现在几家都在说，口径还互相打架。我不拿这个当卖点。**我推的理由很简单：这台有什么别人没有的，我讲给你看。**"

**Q：网上说 XX 牌子更好？**
> "你搜到的那些'深度测评'，很多是投放的。判断方法很简单——**如果一篇文章里某个牌子每项都赢，那就是软文**。真实评测一定有输有赢。"

## 六、促单话术（大件专属）

🔴 **跑步机促单不能用"3、2、1 上链接"的服饰打法**，客单价高、决策链长，硬催会拉高退货率。

```
下单前你记住三件事：

一、破损怎么赔
二、退货运费谁出
三、质保几年、包含哪些部件

这三条我都写在评论区置顶了，你自己核对了再拍。

不着急，今天不下单也没关系，
我更怕你冲动买了又退。
```

**为什么这样促单**：
- 大件用户需要"被允许犹豫"
- 前置售后条款 = 降纠纷
- "怕你退"的表达反而促成理性下单，退货率显著低于催单式

## 七、负面评论应对

| 评论 | 应对 |
|------|------|
| "这么贵，不如买 XXX" | "XXX 确实便宜。不过你对比一下持续马力和跑带尺寸，不是一个级别。预算紧张的话我也可以给你推便宜的，但得说清它少了什么。" |
| "广告，退了" | 不回复或轻描淡写："谢谢反馈~" |
| "买回来吵死了" | "麻烦你看下是不是没铺减震垫。**跑步机扰邻主要是振动不是声音**，加个垫子能改善很多。加客服我远程帮你看。" |
| "用了两周就不想跑了" | "这个真不怪机器，是品类通病。建议你固定一个追剧时间跟跑步绑定，能边看边跑的人坚持率高很多。" |
| "收到有划痕" | 🔴 **立即走破损理赔流程，不要辩解**。这是本品类最容易升级为投诉的场景。 |
