# 立久佳（LIJIUJIA）

## 一句话判断

**永康五金之都出来的性价比玩家，靠"磁悬浮减震"在减震战场上开了第三条路线。** 它是国产四强之外最值得关注的补位选手——**价格更低、有荣耀背书、且减震叙事独树一帜**。

## 基本信息

| 项目 | 内容 |
|------|------|
| 公司 | 浙江立久佳运动器材有限公司 |
| 品牌 | 立久佳 LIJIUJIA |
| **成立** | **2006 年** |
| 总部 | **浙江永康**（中国五金之都） |
| 产能 | **自有生产基地** |
| 定位 | 入门级 / 性价比，跑步机为核心品类 |
| 渠道 | **线上电商旗舰店为主**（京东、天猫、苏宁） |
| **重要合作** | **荣耀亲选**（HONOR Choice）联名 ⭐ |

> 💡 **永康是中国健身器材的产业带核心**。立久佳有自有产线，不是贴牌白牌——这一点和 [[佑美|佑美]] 类似（都有真产能），但它没有佑美那样的口碑塌方记录。

## 🔥 磁悬浮减震（减震战场的第三条路线）

> 完整跨品牌对比见 **[[../tech/减震技术|减震技术]]**

**原理**：利用**磁极相斥**，通过**分布式磁场**产生变化的斥力，使**上下跑板悬浮分离**，主动吸收冲击力。

| | 麦瑞克 | 易跑 | **立久佳** |
|---|--------|------|-----------|
| 路线 | **材料**（超临界发泡 ETPU） | **结构**（悬浮跑板+异硬度减震砖） | **磁力**（磁极相斥悬浮） |
| 卖点 | 回弹率 66%、SGS 认证 | 前后 70/65 Shore A | **"高铁同款磁悬浮"** |

> ⭐ **"高铁有磁悬浮，跑步机也有"是三条路线里传播力最强的比喻。**
> 材料路线要解释什么是超临界发泡，结构路线要解释 Shore A 硬度，**磁悬浮一句话就能让人懂**。这是立久佳被低估的内容资产。

**新款还有 AI 自适应空气减震**（R8）：根据体重自动调节气压缓冲，对关节保护更细腻。

| **R8** | **中端主力** | **¥2,499** | **4.0HP 静音电机（噪音 <45 分贝）**、变频电机、跑带 125cm+×48cm+、**AI 自适应空气减震**、**18 档坡度**、10.1 吋彩屏、**华为 HiLink** |

**有效价格带：¥1,300-2,500**（比 [[麦瑞克|麦瑞克]]/[[舒华体育|舒华]] 低一档）

### H1 的特色功能

- **四种专业模式**：走步 / 燃脂 / 青训 / 强化（覆盖不同年龄段）
- **童锁保护 + 疲劳触发降速** ⭐ 安全设计，家有老人小孩是强卖点
- **高分子自润滑跑板**，免加油，降噪且延长寿命

> ⚠️ **H1 产地为山东青岛**，而立久佳主体在浙江永康——**联名款可能为代工**，需向品牌方核实产线归属。

**定位判断**：立久佳切的是 **¥1,300-2,500 这个"[[亿健|亿健]]和[[佑美|佑美]]中间"的空档**——比佑美贵一点但品控靠谱，比亿健便宜一点但有荣耀背书和差异化减震。

**它是低价档里最安全的选择**：有产能、有品牌联名、无系统性质量丑闻。

## 用户评价

### 正面
- R8 静音表现好（<45 分贝），变频电机平稳
- 磁悬浮/空气减震对膝盖友好，"怕伤膝盖买这台"是常见推荐语
- 荣耀亲选背书带来信任感
- 10.1 吋彩屏 + 华为 HiLink 生态，智能体验超越同价位
- 免加油自润滑跑板，省心

### 负面 / 待观察 ⚠️

| 问题 | 说明 |
|------|------|
| **H1 无坡度调节** | 🔴 **减脂效率打折**，这是 1,799 元档的明显阉割，必须说清 |
| **品牌声量弱** | 抖音/小红书内容量远少于麦瑞克，用户认知度低 |
| **深度差评样本少** | 第三方独立测评不足，长期耐久性缺乏验证 |
| H1 产地存疑 | 浙江品牌但青岛制造，联名款产线归属待核实 |
| 无高端线 | 3,000 元以上无产品，客单价天花板低 |

## 抖音带货分析

### 适配度 ⭐⭐⭐⭐

**优势**：

1. **"高铁磁悬浮"是全品类最好懂的技术比喻** ⭐
   麦瑞克要解释超临界发泡，易跑要解释 Shore A 硬度，**立久佳一句"高铁那个磁悬浮"就讲完了**。在 15 秒短视频里，这个优势是决定性的。

2. **价格带最优** — ¥1,300-2,499 全部落在冲动消费区间，低于国产四强

3. **荣耀亲选背书** — 在低价档里，大厂联名是稀缺信任状（对标 [[小米跑步机|小米生态链]] 逻辑）

4. **R8 参数越级** — 4.0HP 变频 + 18 档坡度 + AI 空气减震 + 华为 HiLink，¥2,499 讲得出故事

5. **童锁 + 疲劳降速** — 家有老人小孩的场景钩子，竞品少提

### 内容策略

**主打钩子**：**"高铁靠磁悬浮不颠，这台跑步机也是"**
→ 立久佳唯一且最强的传播资产。三条减震路线里，只有它能在一句话内讲明白。

**演示动作**：
1. 磁悬浮跑板的上下浮动（手压跑板看分离回弹）
2. 噪音实测（R8 <45 分贝，可用分贝仪对比）
3. 折叠收纳实拍（H1 折后 1570×790mm）
4. 童锁 + 疲劳降速演示（安全场景，家庭用户共鸣强）

**信任状排序**：
1. **荣耀亲选联名**（HONOR Choice）
2. 2006 年成立，浙江永康自有生产基地
3. R8：4.0HP 变频电机、噪音 <45 分贝、18 档坡度、华为 HiLink
4. 高分子自润滑跑板，免加油

**分人群话术**：
- 预算 1,500 内 → 暴汗猛犸

- **要爬坡减脂** → **R8**（❌ 别推 H1，无坡度）
- 家有老人小孩 → 强调童锁 + 疲劳降速

**面对"没听过这个牌子"**：
