# 亿健（YIJIAN）

## 一句话判断

**销量还在，故事没了。** 亿健靠低价在入门段continue走量（精灵 ELF 月销超 3 万件），但它是国产四强里**唯一没有技术叙事的品牌**——在减震、坡度这些主战场上没有牌可打。

## 抖音带货分析

### 适配度 ⭐⭐⭐（原 ⭐⭐⭐⭐⭐，已下调）

**仍然成立的优势**：
1. **价格带友好** — ¥1,600-2,500，落在冲动消费区间
2. **销量社会证明** — 月销 3 万件可讲
3. **售后成熟** — 退货/维修体系稳，账号口碑分风险低
4. **供货稳定** — 不会爆单断货

**下调的原因** 🔴：
1. **没有可演示的技术点** — 折叠一般、减震传统、多数型号无坡度。跑步机内容最缺的就是"可拍的动作"，亿健三个主要演示点（折叠/减震/坡度）都不占优
2. **只能拼价格** — 内容做不出差异化，最后只剩比价，是最累的打法
3. **低价带被立久佳侵蚀** — 对方 ¥1,300 起 + 荣耀背书 + "高铁磁悬浮"一句话讲完的故事

### 内容策略

**亿健的正确用法：做"价格锚"和"稳妥选项"，不做主推。**

**可用钩子**：
- **"月销三万台的那款"** — 社会证明是它唯一的强资产
- **"不折腾，就要个能用五年的"** — 打稳妥、售后好，避开技术比拼

**❌ 不要做的**：
- 不要和麦瑞克/易跑比减震（打不过，且会暴露短板）
- 不要比坡度（多数型号没有）
- 不要讲技术参数（没故事）

**推荐组合打法**：
> 直播间放亿健做"稳妥入门选项"，主推有故事的机型（[[麦瑞克|麦瑞克]] 折叠 / [[易跑跑步机|易跑]] 燃动三模式 / [[立久佳|立久佳]] 磁悬浮）。**亿健负责承接"我就想要个便宜好用的"这类用户。**

## ⚠️ 跑步机品类专属风险（与工学椅完全不同）

> 本表适用于全品类，其他品牌页均引用此处。

| 风险 | 说明 | 严重度 |
|------|------|--------|
| **直播退货率 30-50%** | 远高于传统电商 10-15% | 🔴 |
| **物流破损** | 家用机 50-100kg，物流公司常**不保破损**，仪表盘/电机是重灾区 | 🔴 |
| **退货运费争议** | 大件退货运费高，已有抖音跑步机退运费纠纷判例 | 🔴 |
| **噪音扰邻** | 🔴 **根源是振动而非分贝**，详见 [[../tech/静音与振动\|静音与振动]] | 🔴 |
| **占地与搬运** | 电梯/楼道搬不进去 → 直接退货 | 🟡 |
| **使用率衰减** | "买了不用"是品类原罪 | 🟡 |
| **价格超心理预期** | **主流心理价位 <¥1,000**（见 [[../opportunities/消费人群画像\|人群画像]]），冲动下单后冷静即退 | 🔴 |

> 🔴 **与工学椅的根本差异**：工学椅的风险是"坐着不舒服"，跑步机的风险是**"根本收不到完好的货"或"收到了放不下"**。
