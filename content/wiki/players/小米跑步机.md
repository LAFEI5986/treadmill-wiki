# 小米跑步机

> ⚠️ **带货优先级低**。它是生态链产品而非独立品牌，抖音渠道政策不清晰，且**不参与当前的减震技术竞争**。
> **价值在于理解"大厂生态联名"这套打法**——[[立久佳|立久佳]]×荣耀走的是同一条路。

## 一句话判断

**小米生态链的流量产品，不是利润产品。** 主打性价比 + 米家 IoT 整合，**目标是生态闭环和用户健康数据，不是靠跑步机赚钱**。

## 基本信息

| 项目 | 内容 |
|------|------|
| 推出时间 | 约 2018 年 |
| **制造** | **生态链企业代工，非小米自产** |
| 价格区间 | ¥1,999-3,999 |
| 渠道 | 小米商城、天猫、京东 |
| 生态 | **米家 App**，数据同步 + 智能联动 |

## 产品特点

1. **高性价比** — 同配置价格低 20-30%
2. **米家生态** — 数据同步、智能家居联动
3. **设计简约** — 小米风格，家居友好

## 商业逻辑

| | 说明 |
|---|------|
| 定位 | **流量产品**，利润薄 |
| 真实目标 | 生态闭环，拉动其他品类 |
| 附加价值 | 获取用户健康数据 |

> 💡 **这套逻辑决定了它不会在技术上激进投入**——生态链产品追求"够用且便宜"，
> 不会像 [[麦瑞克|麦瑞克]]/[[易跑跑步机|易跑]] 那样砸钱做减震研发。

## ⭐ 真正的参考价值：大厂生态联名打法

小米生态链模式已被复制到跑步机赛道：

| 品牌 | 大厂背书 | 效果 |
|------|---------|------|
| 小米跑步机 | 米家生态 | 性价比 + 流量 |
| **[[立久佳\|立久佳]] H1** | **荣耀亲选**（HONOR Choice） | ⭐ **低价档的稀缺信任状** |
| [[佑美\|佑美]] F90 | HUAWEI HiLink | 生态兼容 |
| [[立久佳\|立久佳]] R8 | HUAWEI HiLink | 生态兼容 |

> ⭐ **对带货的启示**：在低价档，**用户没听过品牌，但听过荣耀/华为/小米**。
> 大厂联名是最高效的信任建立方式——比讲参数快得多。
>
> 话术示例：*"你可能没听过立久佳，但你听过荣耀吧？这台是荣耀亲选的联名款。"*

## 抖音带货判断

**适配度 ⭐⭐（低优先级）**

| 维度 | 判断 |
|------|------|
| 价格带 | ✅ ¥1,999-3,999 尚可 |
| 品牌信任 | ✅ 小米认知度高 |
| **技术故事** | 🔴 **无**——不参与减震/坡度竞争 |
| **演示点** | 🔴 **弱**——折叠、减震均无突出表现 |
| 渠道政策 | ⚠️ 生态链产品，抖音达人合作政策不清晰 |
| 售后 | ⚠️ 代工模式，责任链条长 |

> **结论**：小米品牌力可用，但**没有可演示的差异点**，做不出内容。
> 同价位有更好选择（[[立久佳\|立久佳]] R8、[[麦瑞克\|麦瑞克]] 小白犀）。
