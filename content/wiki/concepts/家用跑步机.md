# 家用跑步机

> 📌 **本库的主体品类**。抖音带货 95% 的动作都发生在这里。

## 定义与市场

面向家庭用户的跑步机，核心诉求是**静音、占地小、性价比**——注意这三个诉求都不是"性能"。

| 指标 | 数据 |
|------|------|
| 2025 国内市场规模 | **187.6 亿元（+13.2%）** |
| 2026 预测 | 突破 210 亿元 |
| 2021 需求量 | 约 990.4 万台 |

详见 [[../maps/行业概览|行业概览]]。

## 🔴 价格带的真相

**这是本页最重要的一段。**

| | 价格 |
|---|------|
| **用户主流心理价位** | 🔴 **<¥1,000（占 40%）** |
| **品牌实际主力定价** | **¥1,500-4,000** |

> 🔴 **这个 gap 是退货率 30-50% 的根本原因**——超心理预期的冲动下单，冷静后就退。

## 核心参数（按实际重要性排序）

> ⚠️ **注意：这个排序和品牌宣传的重点是反的。** 品牌爱讲马力，用户真正在意的是空间和噪音。

| # | 参数 | 为什么重要 | 详见 |
|---|------|-----------|------|
| **1** | **折叠与占地** | **第一退货原因是"放不下"** | [[../tech/折叠与收纳\|折叠与收纳]] |
| **2** | **噪音与振动** | 🔴 **扰邻是独有退货原因**；真凶是振动不是分贝 | [[../tech/静音与振动\|静音与振动]] |
| **3** | **减震** | 膝盖负担 + 抑制振动（双重价值） | [[../tech/减震技术\|减震技术]] |
| 4 | **坡度** | 减脂效率；大体重/膝盖敏感人群的解法 | [[../tech/坡度系统\|坡度系统]] |
| 5 | **跑带尺寸** | 人机匹配，决定适不适合你的身高 | [[../tech/跑带与跑板\|跑带与跑板]] |
| 6 | **电机** | 🔴 **最大参数陷阱**：峰值 ≠ 持续 | [[../tech/电机技术\|电机技术]] |

### 三个必须知道的参数陷阱

1. **马力越大越好** → 家用标**峰值**，商用只标**持续**；1 CHP 带 50-60kg
2. **"静音"就不扰民** → 扰楼下的是**振动**（结构传导），不是分贝
3. **32 档坡度 = 很陡** → **档位 ≠ 角度**

## 使用场景

| 场景 | 说明 |
|------|------|
| 天气不好 / 雾霾 | 最原始的需求 |
| 夜跑安全顾虑 | **女性用户尤其在意**（女性占比 >65%） |
| **边跑边看剧** ⭐ | **决定坚持率的关键**——能边看边跑的人复购率高得多 |
| 带娃间隙锻炼 | 精致妈妈人群的核心场景 |
| 康复慢走 | 银发/术后人群 |

> 💡 **"边跑边看剧"是被低估的场景**。跑步机最大的敌人是无聊，不是难受。
> 直播答疑可以直接问："你打算边跑边看什么？"——想不出来的人，大概率会闲置。

## 购买决策因素（真实排序）

| # | 因素 | 说明 |
|---|------|------|
| 1 | **空间** | 嘴上问性能，实际卡在放不下 |
| 2 | **价格** | 心理价位 <¥1,000 |
| 3 | **噪音/扰邻** | 住楼房的第一顾虑 |
| 4 | **会不会闲置** | 品类原罪，用户自己也怕 |
| 5 | 品牌与售后 | 大件维修成本高 |
| 6 | 性能参数 | **排最后**，且多数用户看不懂 |

## 与商用的区别

| 维度 | 家用 | [[商用跑步机\|商用]] |
|------|------|------|
| 价格 | ¥1,000-10,000 | **¥4.5 万 - 18 万** |
| 日均使用 | 1 小时 | **12-16 小时，全年无休** |
| 马力标注 | **爱标峰值**（数字好看） | **只标持续**（真实耐力） |
| 折叠 | 核心卖点 | 基本不折叠 |
| 采购逻辑 | 冲动/家庭决策 | 招投标、关系营销 |

> ⭐ **"家用 vs 商用"是最强的避坑内容素材**：健身房那台 ¥16 万的机器只标持续马力，一句话就能拆穿家用机的参数虚标。

## 当前产品趋势

1. **轻量化 · 折叠化 · 小户型适配** — 紧凑型设备备受青睐
2. **减震军备竞赛** — 材料 / 结构 / 磁力三条路线（见 [[../tech/减震技术|减震技术]]）
3. **爬坡成中端标配** — 2024-2026 最大增量需求
4. **智能生态整合** — HUAWEI HiLink、荣耀亲选（见 [[智能跑步机|智能跑步机]]）

## ⚠️ 品类带货特殊性

| | 工学椅 | **家用跑步机** |
|---|--------|--------------|
| 直播退货率 | 一般 | 🔴 **30-50%** |
| 单件重量 | 20-30kg | 🔴 **50-100kg** |
| 主要退货原因 | 坐着不舒服 | 🔴 **收不到完好的货 / 放不下 / 楼下投诉** |
| 物流风险 | 低 | 🔴 **物流公司常不保破损** |

**核心方法论**：[[../opportunities/话术与卖点#二开场话术劝退式筛人|劝退式开场六问]]——住几楼？楼下住人吗？木地板还是瓷砖？电梯能进吗？谁搬？量过尺寸吗？

> **在这个品类，筛人就是利润管理。**
